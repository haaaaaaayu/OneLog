## 이번 최종 보정

1. 식단 관리의 요리 진입을 곧바로 수량 폼으로 보내지 않고 Figma 레시피 상세를 먼저 거치도록 연결했다.
2. 식단 변경 화면의 불필요한 상태 카드를 제거하고 제목·설명·네 선택지·고정 버튼의 좌표와 간격을 맞췄다.
3. 요리 완료 화면에 Figma 원본 마스코트를 사용하고 재료 결과 카드와 두 버튼의 높이·순서를 맞췄다.
4. 남은 재료 활용을 루트 식단관리 흐름으로 되돌려 하단 탭을 유지했다.
5. AI 채팅의 안전영역, 상태 배지, 제안 카드, 입력 독을 Figma 좌표에 맞추고 레시피 적용은 상세 화면에서 확정하도록 정리했다.
6. 기간 선택, AI fixture 응답, 일정 변경, 레시피 상세, 요리 완료, 남은 재료, 조리 시간·도구 시트를 캡처 하네스에 추가했다.
7. 레시피 탐색(707:881)을 393×852 원본과 다시 대조해 카드 169.5×220pt, 열 간격 14pt, 시작 x 21.5/205pt, 행 y 419/651pt, 하단 탭 y 778pt로 고정했다. 상단은 고정하고 결과만 스크롤하며, 사진·하트·문구의 카드 내부 클리핑과 마스코트 109×55pt 크롭을 보정했다. 기본 추천은 Figma처럼 4개만 노출하고, 검색·필터 시에는 전체 적합 결과를 유지한다.

## 판정 경계

- 레시피명, 재료명·잔량, 이웃 글, 날짜와 예산은 실행 데이터이므로 Figma 샘플 문자열과 다를 수 있다. 같은 상태의 컴포넌트 구조, 타이포 위계, 카드·버튼·안전영역 배치를 판정 기준으로 삼았다.
- 네트워크 이미지가 아직 내려오지 않은 순간에는 같은 크기의 플레이스홀더가 보이며 레이아웃은 유지된다.
